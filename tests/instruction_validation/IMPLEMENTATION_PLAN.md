## Test Organization

Tests are now organized as numbered binaries (test_001 through test_118) generated by `generate_test_binaries.py`. Each test validates specific instruction behavior using the `InstructionEncoder` class for precise binary generation.

### Quality Metrics

For each instruction, ensure:
- ✅ Basic functionality test
- ✅ All variants tested (immediate, register, byte, word)
- ✅ Flag behavior verified
- ✅ Edge cases covered
- ✅ Register independence verified
- ✅ Source preservation verified (where applicable)
- ✅ Integration with other instructions
